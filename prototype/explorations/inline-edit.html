Inline editing: three styles

The same project and the same fields, edited the way HubSpot, Zoho and Linear do it. Everything here is live: click the values. Nothing is saved anywhere, and this page is not part of the Step 7 prototype. Try a wrong value (letters or a negative budget, a contract number longer than 12 characters) to see how each style reports an error.

HubSpot style

  • Hover shows a pencil; click turns the value into an input in place.
  • No buttons. Saves on Enter or when you click away; Esc puts the old value back.
  • Dropdowns and the checkbox save the moment you choose; Pick several saves when you click away.

Zoho style

  • Hover shows a pencil and a dotted underline; click opens the input with a tick and a cross beside it.
  • Saves only with the tick or Enter; the cross or Esc cancels. Clicking away leaves it open.
  • Same for every type, including dropdowns and Pick several.

Linear style

  • Name and description are always editable text and autosave as you type.
  • Each property is a quiet button; choices open a small popover with search and save when you pick.
  • Pick several stays open and saves every tick; the date is a calendar popover; Esc closes.

Fields shown: name, description (long text), budget (number), contract number (text, max 12), customer tier (pick one), channels (pick several), go-live (date), VIP (checkbox), account manager (person).
