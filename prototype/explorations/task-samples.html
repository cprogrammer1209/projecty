Task view: three styles to choose from

The same sample project (Website Revamp, key WEB: 3 task lists, 18 tasks) shown the way Zoho Projects, Linear and Jira show it. Open each one and try the list, the board (drag a card to another column), and the task detail.

Zoho style

Tasks grouped under task-list headers with a column table. Task detail is a full page: details on the left, content in the middle, comment and activity tabs on the right.

Linear style

Dense, quiet rows with inline pickers on the status, priority and person. Keyboard first (J/K, S, P, A, C, Space to peek). Issue page with properties on the right.

Jira style

Backlog sections, a List table and a board with swimlanes. Detail opens as a drawer or modal with a status transition button and a Details panel.

What is the same in all three: the data (task-model.js), four statuses (Open, In Progress, In Review with type Open, Closed with type Closed), priorities, owners, due dates (some overdue), sub tasks, tags, two custom fields (Effort and Customer visible), comments and activity on several tasks, grouping, filters, quick add, a view switcher and a portal-level My tasks entry in the sidebar. Data lives in memory (reload resets it).
