Settings page: four styles to choose from

The same module-wise Settings (Portal, then Modules → Projects: Fields, Layouts, Statuses, Templates) built four ways. Open each one and try the Layouts page, which holds the project layout builder.

Zoho style

Setup sidebar, three-panel layout editor: new fields and unused fields on the left, canvas in the middle, properties on the right.

HubSpot style

Objects tree, property-group cards you drag fields between, available properties on the right, edit and preview.

Linear style

Quiet, keyboard-first. A document-like builder with a move popover, command palette and a live preview column.

Jira style

Project-settings sidebar with a module switcher, issue-layout groups, hidden fields and preview tabs.

What is the same in all four: the module-wise structure (future modules such as Tasks and Issues already have a place), the layout rules (up to 3 layouts, unique section names, hidden fields keep their answers, the default layout can't be deactivated), overrides per field (required, read-only, default), drag and drop with a keyboard alternative, and a live preview. Data lives in memory (reload resets it).
