Learn by building

An event-driven microservice map of ProjectY

What is already built, what you can add next, how each piece works and in which order to learn it. Everything here is clickable: boxes in the diagrams explain themselves, and link to a tool card with what it does in this project and what to practise.

Database per service

Platform and Work each own their data. Nobody reads another service's tables.

Events, not calls

Services react to Kafka events. Adding a consumer never changes a producer.

Reliable by construction

Transactional outbox on the way out, idempotent consumer on the way in.

Verify locally

Tokens are checked with Platform's public keys; permissions come from a local copy built from events.
